Guessing Game

Project Name: Guessing Game

Language: Python

Description: A simple console-based number guessing game. The computer generates a secret number between 1 and 100, and the user has to guess it. The program gives hints such as "Too High" or "Too Low" until the correct number is guessed.

How to Run:
1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

bash
python guessing_game.py
